## Development

1. Install [rustup](https://www.rust-lang.org/tools/install) (Rust toolchain manager).
2. Install [just](https://github.com/casey/just) (taks runner).
3. Install [cargo-binstall](https://github.com/cargo-bins/cargo-binstall) (binaries installer).
4. Run `just setup` to install additional binary dependencies.
5. Run `just` to see other available recipes.
